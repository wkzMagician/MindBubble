## 默认折叠的导入帮助

以下列出原常驻指引。文件导出指引改为按需展开；三种 API 指引折叠并精简为授权、权限与取得 Token 的必要动作，删除实现细节及重复操作说明。

| 来源 | 原常驻指引 |
| --- | --- |
| Obsidian | 推荐选择 Vault 根目录；也可选择包含笔记和附件的 ZIP，或若干 Markdown 文件。 |
| Notion | 在 Notion 导出为 Markdown & CSV，选择得到的 ZIP 文件。 |
| Evernote | 在 Evernote 导出 .enex 文件，支持选择多个文件或包含 ENEX 的 ZIP。 |
| Google Keep | 通过 Google Takeout 导出 Keep，选择 Takeout ZIP 或其中的 JSON 文件。 |
| Microsoft OneNote | 选择转换得到的 HTML 或 ZIP。OneNote 原生 .one 格式需要先转换。 |
| 思源笔记 | 选择思源导出的 Markdown 文件夹或 ZIP；移动端可导入导出包。 |
| 语雀 | 选择 Markdown / HTML 导出文件或文件夹。API 接入需要相应授权，当前使用文件导入。 |
| FlowUs 息流 | 从 FlowUs 导出页面，选择 Markdown / HTML / CSV 文件或 ZIP。API 接入尚需单独授权配置。 |
| 飞书文档 | 选择转换为 Markdown、HTML 或 CSV 的文件。原生飞书 Docx、Word、PDF 和开放平台连接尚未实现。 |
| flomo 浮墨笔记 | 从 flomo 导出 HTML/ZIP，建议选择 ZIP，以同时提取 file/ 目录中的图片附件。 |
| 通用导入 | 支持 Markdown、HTML、JSON、CSV、XLSX、ENEX、ZIP、文件夹。Logseq Graph 可选择 Markdown 目录。 |
| Notion API | 1. 在 Notion 创建 Internal Integration，复制 Integration Token。<br>2. 将需要导入的页面共享给该 Integration。<br>3. 填写 Token 并点击读取；仅导入授权可访问的页面。 |
| OneNote Graph | 使用具有 Notes.Read 权限的用户委托 Access Token。此处提供临时令牌导入；每次读取需有效令牌，OAuth 一键授权尚未配置。 |
| 思源 API | 在电脑端运行思源笔记，从设置 → 关于取得 API Token。MindBubble 将连接本设备 127.0.0.1:6806 的内核读取最多 200 篇文档。移动端建议使用 Markdown 导出包。 |
